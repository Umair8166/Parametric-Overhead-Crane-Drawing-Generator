# Parametric Overhead Crane Drawing Generator

Full-stack web application that generates a dimensioned 2D drawing of a single-girder, top-running EOT (Electric Overhead Travelling) crane from user inputs, and lets users save, list, reopen, and edit designs.

## Quick start

Requires **Node.js 20+** (built and tested on Node 24; see `.nvmrc`).

```bash
npm install
npm start
```

Open `http://localhost:3000`.

For development with hot reload:

```bash
npm run dev
```

To run the test suite:

```bash
npm test
```
